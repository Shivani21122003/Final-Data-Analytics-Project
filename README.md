# Final Data Analytics Project – Titanic Dataset

## Project Overview
This project was completed as part of the SWYNEX Technologies Data Analytics task. It demonstrates data cleaning, exploratory data analysis (EDA), and dashboard creation using the Titanic dataset.

## Problem Statement
The goal is to clean and analyze Titanic passenger data to understand survival patterns based on passenger gender, class, and other available information.

## Dataset Information
The dataset contains passenger details such as age, gender, passenger class, fare, embarkation port, and survival status.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Power BI
- GitHub

## Data Cleaning
- Checked for missing values and duplicate records.
- Filled missing Age values using the median (28.0).
- Filled missing Fare values using the median (14.4542).
- Filled missing Embarked values using the most frequent value (S).
- Checked the dataset after cleaning.

## Exploratory Data Analysis
The analysis identified survival patterns across gender and passenger class.

Key findings:
- Overall survival rate: 38.24%
- Female survival rate: 72.75%
- Male survival rate: 19.19%
- First-class survival rate: 62.04%
- Second-class survival rate: 42.96%
- Third-class survival rate: 25.53%

## Power BI Dashboard
An interactive Power BI dashboard was created with:
- Total Passengers
- Total Survivors
- Survival Rate
- Average Fare
- Survival analysis by gender and passenger class
- Slicers for gender, passenger class, and embarkation port

## Business Insights
- Female passengers had a higher survival rate than male passengers.
- First-class passengers had a higher survival rate than passengers in second and third class.
- Passenger class and gender were important factors associated with survival.
